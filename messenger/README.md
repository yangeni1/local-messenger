# Мессенджер

Мини-чат на чистом Node.js: HTTP-статика + собственный WebSocket, **без npm-зависимостей**.

## Локально

```powershell
cd messenger
node server.js          # http://localhost:8090
```

Открой http://localhost:8090 в двух вкладках — это два разных пользователя.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8090` | порт |
| `HOST` | `0.0.0.0` | `127.0.0.1` — только локально |
| `CHAT_TOKEN` | — | пароль на вход. Сервер хранит только SHA-256 хеш |

## Деплой на Render (бесплатный tier)

1. Запушь папку `messenger` в GitHub (содержимое репозитория — файлы этой папки).
2. Render → **New → Web Service** → выбери репозиторий.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: *(пусто)*
   - **Start Command**: `node server.js`
   - **Instance Type**: Free
4. **Environment** → добавь `CHAT_TOKEN` = длинный случайный пароль.
5. Deploy. Получишь `https://<имя>.onrender.com`.

Railway: то же самое, Start Command `node server.js`, переменная `CHAT_TOKEN`.

> Free-инстансы Render засыпают без трафика — первый заход после простоя грузится ~30 секунд.

## Безопасность

- вход по паролю (сравнение хешей в `timingSafeEqual`, сам пароль на сервере не хранится)
- статика отдаётся только с разрешёнными расширениями и не выходит за `public/`
- rate limit: 10 сообщений / 10 сек на соединение
- пользовательский текст рендерится только через `textContent` (XSS невозможен)
- история сообщений хранится в памяти, при перезапуске теряется

## Уведомления

- кнопка **🔔 Уведомления** в сайдбаре — включает системные пуши браузера (нужен https или localhost)
- счётчик непрочитанных в заголовке вкладки, мигание «💬 Новое сообщение» на скрытой вкладке
- короткий звуковой сигнал на новое сообщение и отдельный — на упоминание
- упоминание через `@ник` подсвечивает сообщение и уведомляет даже при открытом чате
- выбор «вкл/выкл» запоминается в браузере, кнопка показывает текущее состояние

## Телефон

- сайдбар (профиль, онлайн, уведомления, подсказки) выезжает по кнопке ☰ или свайпом от левого края
- закрывается тапом по фону, кнопке ✕, свайпом влево или Esc
- в шапке видно, сколько человек онлайн; поле ввода 16px — iOS не зумит страницу
- тап по нику в онлайне вставляет `@ник` в поле ввода
- ник меняется в своей карточке (✎), без системного `prompt`
- учтены «челки» и домашние полоски: `env(safe-area-inset-*)`, `100dvh`
- экраны входа и смены ника на телефоне открываются снизу, как шторка
